# 📊 Retail Sales Analysis Dashboard

## 📌 Project Overview

This project is an interactive Power BI dashboard built to analyze retail sales performance across products, customers, regions, and time. The dashboard provides business insights through KPIs, interactive visualizations, and dynamic filters.

---

## 🎯 Objectives

- Monitor overall sales performance
- Analyze product performance
- Identify top customers
- Compare regional sales
- Discover sales trends over time

---

## 📈 Dashboard Pages

### 1. Executive Dashboard
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Customer Count KPI
- Sales Trend
- Category Analysis
- Segment Analysis
- Interactive Slicers

### 2. Product Analysis Dashboard
- Top 10 Products
- Bottom 10 Products
- Sales by Category
- Profit by Category
- Discount vs Profit
- Product Details

### 3. Customer Analysis Dashboard
- Top Customers by Sales
- Top Customers by Profit
- Customer Segmentation
- Customer Details

### 4. Regional Analysis Dashboard
- Sales by Region
- Sales by Country
- Sales by State
- Regional Performance

### 5. Time Analysis Dashboard
- Monthly Sales Trend
- Quarterly Sales
- Weekly Sales
- Profit Trend
- Monthly Summary
